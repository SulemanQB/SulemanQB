  FastAPI **image classification** for plant disease. Held-out top-1 is **79.26%** on a small split.

- 🛰️ **aerial-building-seg**
  https://github.com/SulemanQB/aerial-building-seg
  **U-Net segmentation** of buildings on aerial tiles.

- 🎥 **multi-object-track**
  https://github.com/SulemanQB/multi-object-track
  **YOLO detection** plus a tracker.

  FastAPI prediction service with latency metrics and a KS drift check. The default classifier is a **color heuristic**, not a trained model.

  https://github.com/SulemanQB/FedMetaBench
  **Federated learning** meta-learning benchmark.

  https://github.com/SulemanQB/SDFN

- 📚 **research-rag-agent**
  https://github.com/SulemanQB/research-rag-agent
  Retrieval over **NIST AI documents**. The 5/5 figure is document retrieval, not answer quality.

- 🔒 **fed-dp-demo**
  https://github.com/SulemanQB/fed-dp-demo

- 📓 **FedMeta_MNIST**
  https://github.com/SulemanQB/FedMeta_MNIST
  **FedAvg** notebook. **98.72%** is old Colab output, not a new run.

- 📊 **demand-forecasting-sql**
  https://github.com/SulemanQB/demand-forecasting-sql
  Retail demand forecasting with DuckDB SQL features, LightGBM (Tweedie) and rolling-origin backtesting; about 10% lower 28-day order-quantity error than a moving-average baseline.
